# Web Projects by Year

90 very small HTML, CSS and JavaScript projects, 10 for each year from 2018 to 2026.

All of them were built in November 2026. Each year label names the web design style the project imitates, not the date it was made, and the style labels are loose approximations.

Open any project's `index.html` in a browser. There are no dependencies or build steps.
